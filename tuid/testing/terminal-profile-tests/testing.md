# Testing: Terminal Profile Matrix

Layer 7 — only where portability matters. Representative profiles:

```text
baseline terminal · truecolor terminal · limited color · multiplexer
SSH · narrow viewport · legacy keyboard encoding · enhanced keyboard
```

Do not pretend exhaustive terminal compatibility is practical if the project
does not require it. Select profiles from the capability policy
(`../../aspects/terminal-capabilities/`): test what the policy claims to
support, at the fallback rungs it promises.
